Dynasties — Mechanics Build v20

Map Editor update:
- Rebuilt Create Map as a Wargroove-style editor screen.
- Added supplied Terrain and Units toolbar icons at the top of the map.
- Terrain palette currently includes Grass and the supplied Sea tile.
- Terrain can be painted by tapping or dragging across the editor map.
- Sea is genuinely impassable in gameplay and AI pathfinding.
- Units palette includes Soldier, Archer and Cavalry for both White Walkers and Lannister.
- Units placed in the editor become the starting units when that saved map is used for New Game.
- Added Remove option for placed starting units.
- Units cannot be placed on sea or on the fixed castle footprints.
- Fixed castles remain visible in the editor for now; additional editor tools can later make them movable/placeable.
- Map saving requires at least one starting unit for each side.
- Fixed Load Game validation to use the current save version.
- Fixed clicking any tile of a 2x2 castle so it selects the correct castle.
