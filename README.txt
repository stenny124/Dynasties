Dynasties — Mechanics Build v23

MAP IMPORT / EXPORT
- Create Map now opens a map-library screen rather than immediately creating a blank map.
- Create New Map starts a fresh editor map.
- Import Map accepts .dynmap or JSON Dynasties map files.
- Imported maps are stored in the same local map library as maps made on that device.
- Every stored map has Edit and Export buttons.
- Export downloads a portable .dynmap file containing map dimensions, terrain, starting units and HQ positions.
- Import validates dimensions, terrain, unit types and HQ locations before adding the map.

EDIT EXISTING MAPS
- Any map previously created on the device can be reopened in the editor.
- Any imported map can also be reopened and edited.
- Saving an existing map updates that same library entry rather than creating duplicates.
- Saving a new map adds a new library entry.
- After saving, the UI returns to the Create Map library.

CROSS-DEVICE WORKFLOW
1. Create/edit a map on laptop.
2. Open Create Map and press Export on that map.
3. Move/share the .dynmap file to the phone.
4. On the phone open Create Map > Import Map and choose the file.
5. The imported map appears under New Game and can also be edited/re-exported.

SAVE COMPATIBILITY
- v22 three-slot saves remain loadable in v23.
